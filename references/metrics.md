# 指标与统计口径

## 周期、截点与样本

统计周期按寄件日期界定，起止日均包含。周报最多 7 个日历日；月报限同一个日历月。数据截点 `as_of` 与报告出具日期分开：签收时间晚于截点的快件，在本次截点下尚未签收。

运单数指规范化、校验及去重后的有效运单数。缺失必要字段、无效日期、重复记录等由质量附件解释。件数和重量使用源字段；缺失或无效数据应查看质量提示，不能把估算值解释为实测值。

缺少整个签收字段时，该文件的运单无法支持签收及 SLA 评价；缺少整个备注字段时，无法评价全量异常率。多文件中这些字段覆盖不足的相关总体比率显示不适用，并列出覆盖票数。签收列存在但单元格为空，才按源记录未签收处理；备注列存在且为空表示未提供异常备注。

## SLA 与条件时效

| 指标 | 分子 / 分母与限制 |
|---|---|
| 签收率 | 截点前已签收的有效运单 / 有效运单。周期末仍在途会影响此值。 |
| SLA 到期样本 | 寄件时间精确、截至截点已经经过适用 SLA 时限的有效运单。省份配置可覆盖默认时限。 |
| SLA 达成率 | 到期样本中在适用 SLA 内完成签收的运单 / SLA 到期样本。已超时仍未签收的运单计入分母。 |
| 已签收样本 24/48/72h 率 | 精确且有效的已签收时效样本中，分别在 24/48/72 小时内签收的运单 / 该已签收时效样本。属于条件时效，不等于全量 SLA 达成率。 |
| 平均/中位/最快/最慢时效 | 有效精确已签收样本的签收时间减寄件时间，单位小时。月内周平均按运单数加权。 |
| 尚未到 SLA 的样本 | 尚未经过适用 SLA 的可评价运单，包括提前签收件；不纳入本期成熟分母，不当作全部已达成。 |

无到期样本时，SLA 达成率不适用。日期粒度不能支持精确小时评价；仅有日期的记录单列提示，不用虚构的零点时刻评价精确 SLA。签收时间无法解析、精确签收早于寄件，或日期签收明确早于寄件日的记录单列为签收待核实，不参与可信签收和 SLA 评价。签收率与时效指标的有效证据要求因此不同，排除数量均在质量附件中披露。

逐票 SLA 状态保存在 `shipments.csv`：`pending` 为尚未成熟，`on_time` 为到期且准时签收，`late_signed` 为到期但超时签收，`overdue_unsigned` 为到期未签收，`precision_insufficient` / `time_invalid` 为精度不足或无效时间。摘要最多展示八个主要及需关注省份，优先补充低达成线路；完整线路见 `province.csv`。

默认参考时限为 72h，参考目标为 98%；客户配置中的 `sla_hours`、`sla_target`、`province_sla_hours` 可覆盖。参考目标是分析规则，已有服务承诺由独立配置字段提供。

## 异常分类与处理进展

备注先规范化空值，再按规则识别。正常在途、客户预约约定、物流异常和未识别备注分别展示。复合备注中的异常不能仅因含“在途”而忽略；无法明确归类的内容保留待核实，不直接当作确认异常。

异常率为已识别物流异常运单 / 有效运单。客户预约约定单独列示；备注分类是源文字的规则判断，不能证明异常已解决或推断实际责任。完整备注及分类结果保留在 `exceptions.csv` / `review.csv`。

处理台账使用 `pending`、`in_progress`、`closed` 状态。仅有状态“已闭环”而缺少 `evidence` 时，不计入已核实闭环。措施、负责人、截止时间和进展来自台账；自动生成的改善建议不能作为执行记录。

## 对比与溯源

本期与上期应使用相同字段定义、SLA 规则与时间精度。周期长度、截点、字段覆盖或样本口径不同会影响环比，应结合质量提示解读。百分率变化使用百分点，数量变化使用数量或相对百分比；低基数和空样本不得生成确定的改善结论。

JSON 统计与质量附件、逐票与线路 CSV、manifest 保留本次生成的依据。`metrics.json` 的 `comparison` 保存比较使用的上期指标、观察时刻和来源哈希；历史快照需与本期配置及周期末观察滞后一致，不能直接混用。复核时先检查有效/剔除数量与指标分母，再核对源记录；不要只凭摘要中的颜色或概况评价判断业务表现。
